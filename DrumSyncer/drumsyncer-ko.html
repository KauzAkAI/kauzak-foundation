드럼싱커

v2.0 — drumsyncer.com — 카우작 재단

AI 기반 드럼 커버 영상 제작. 영상을 업로드하거나 YouTube 링크를 붙여넣으세요 — 드럼싱커가 드럼과 음악을 분리하고, 비트를 맞추고, 모든 것을 자동으로 영상에 싱크합니다.

두 가지 모드, 하나의 도구

품질 테스트든 완성된 콘텐츠 제작이든.

테스트 모드

드럼 커버 영상을 가져와 드럼과 배킹 트랙을 분리한 후 다시 조합하여 싱크 품질을 확인합니다. 프로덕션 전 워크플로우 검증에 적합합니다.

  • 입력: 드럼 커버 영상 1개 (업로드 또는 YouTube URL)
  • 처리: 분리 → 분석 → 재조합
  • 출력: 싱크된 영상 + 드럼 전용 + 배킹 전용

프로덕션 모드

원곡, 드럼 녹음, 영상을 가져와 비트에 맞춰 완벽하게 정렬된 완성품을 만들어냅니다.

  • 입력: 원곡 + 드럼 녹음 + 영상
  • 처리: 분리 → 정렬 → 믹스 → 내보내기
  • 출력: 프로덕션 레디 싱크 영상

기능

음악가를 위해 제작. AI로 구동.

🌐

YouTube 통합

YouTube URL을 붙여넣으면 yt-dlp를 통해 영상을 자동으로 다운로드합니다. 수동 다운로드가 필요 없습니다.

🧠

AI 스템 분리

Meta의 Demucs v4 신경망을 사용하여 어떤 곡에서든 스튜디오 품질의 정확도로 드럼을 분리합니다. 클린 스템이 필요 없습니다.

📈

완벽한 비트 싱크

온셋 강도 엔벨로프의 상호상관 분석으로 밀리초 단위까지 트랙 간 정확한 정렬 오프셋을 찾습니다.

🎨

드래그 & 드롭 인터페이스

드래그 앤 드롭 파일 업로드가 가능한 깔끔한 웹 기반 UI. 실시간 진행 추적으로 파이프라인의 현재 위치를 정확히 보여줍니다.

🇰🇷

이중 언어 EN/KR

원클릭 언어 전환이 가능한 완전한 영어 및 한국어 인터페이스. 국제적인 드럼 커버 크리에이터를 위해 제작되었습니다.

시스템 요구 사항

드럼싱커를 실행하기 위해 필요한 것들.

운영 체제

Windows 10/11 (64비트). 자동 설치 프로그램이 Windows에서 모든 설정을 처리합니다.

메모리

최소 8 GB RAM. 긴 트랙과 빠른 처리를 위해 16 GB 권장.

저장 공간

소프트웨어용 2 GB 여유 디스크 공간. 처리 중 영상 파일을 위한 추가 공간 필요.

GPU (선택 사항)

CUDA 지원 NVIDIA GPU가 Demucs 분리를 가속합니다. GPU 없이도 CPU 모드로 작동 — 시간이 더 걸릴 뿐입니다.
