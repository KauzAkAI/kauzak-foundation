Two Modes, One Tool

Whether you're testing quality or producing finished content.

Test Mode

테스트 모드

Takes a drum cover video, separates the drums from the backing track, then reassembles to verify sync quality. Perfect for validating your workflow before production.

  • Input: One drum cover video (upload or YouTube URL)
  • Process: Separate → Analyze → Reassemble
  • Output: Synced video + drums-only + backing-only

Production Mode

프로덕션 모드

Takes an original song, a drum recording, and a video. Syncs them all together into a finished product with beat-perfect alignment.

  • Input: Original song + drum recording + video
  • Process: Separate → Align → Mix → Export
  • Output: Production-ready synced video

Features

Built for musicians. Powered by AI.

🌐

YouTube Integration

Paste a YouTube URL and DrumSyncer downloads the video automatically via yt-dlp. No manual downloading needed.

🧠

AI Stem Separation

Uses Meta's Demucs v4 neural network to isolate drums from any song with studio-quality accuracy. No clean stems required.

📈

Beat-Perfect Sync

Cross-correlation of onset strength envelopes finds the precise alignment offset between tracks down to the millisecond.

🎨

Drag & Drop Interface

Clean web-based UI with drag-and-drop file upload. Real-time progress tracking shows exactly where you are in the pipeline.

🇰🇷

Bilingual EN/KR

Full English and Korean interface with one-click language toggle. Built for international drum cover creators.

⚙

Auto-Installer

One-click Windows installer downloads and configures Python, FFmpeg, yt-dlp, PyTorch, and all dependencies automatically.

System Requirements

시스템 요구 사항

Operating System

Windows 10/11 (64-bit). The auto-installer handles all setup on Windows machines.

Memory

8 GB RAM minimum. 16 GB recommended for longer tracks and faster processing.

Storage

2 GB free disk space for software. Additional space needed for video files during processing.

GPU (Optional)

NVIDIA GPU with CUDA support accelerates Demucs separation. CPU mode works without GPU — just takes longer.
